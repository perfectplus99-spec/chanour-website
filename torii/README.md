# เว็บแฟรนไชส์ชาโทรี่ (CHATORY) — `/torii/`

เว็บสำหรับนักลงทุนที่สนใจแฟรนไชส์ชาโทรี่ แยกโฟลเดอร์จากเว็บชานัว (ไม่แตะไฟล์ของชานัว)
ทุกลิงก์ในโฟลเดอร์นี้เป็นลิงก์แบบสัมพัทธ์ ย้ายทั้งโฟลเดอร์ไปใช้กับโดเมนของชาโทรี่เองได้เลย

| หน้า | ไฟล์ |
|---|---|
| หน้าหลัก | `index.html` |
| เช็คทำเลว่าง | `check-branch/index.html` (ตั้งค่าที่ `check-branch/config.js`) |

## สิ่งที่นำมาจากเว็บชานัว

- **รูปแบบร้าน**: การ์ด 3 ขนาด (TORii mini · TORii Kiosk · CHATORY Store) พร้อมตารางเทียบ
- **ตัวคำนวณคืนทุน**: เลือกขนาดร้าน → เลือกสถานการณ์ขาย → ปรับยอดขาย ราคาเฉลี่ย ค่าเช่า และพนักงาน แล้วดูกำไรต่อเดือนและเดือนที่คืนทุน
- **เช็คทำเลว่าง**: ใช้ระบบเดียวกับชานัว (เลือกจังหวัด อำเภอ ปักหมุด)
- ฟอร์มสร้างข้อความสมัครส่งทาง LINE และแถบปุ่มลัดล่างจอบนมือถือ

## แก้ราคาแพ็กเกจ / ค่าเริ่มต้นตัวคำนวณ

เปิด `index.html` แล้วหา `const SITE = {` (ท้ายไฟล์)

- `invest` = งบลงทุนของแต่ละแบบ (ตัวเลขในการ์ด ตาราง ส่วนหัว และตัวคำนวณ จะเปลี่ยนตามทั้งหมด)
- `addon` = ราคาซุ้มที่สั่งเพิ่ม (ตอนนี้มีเฉพาะ TORii Kiosk)
- `cups` `price` `rent` `staff` = ค่าเริ่มต้นตอนเลือกแบบนั้นในตัวคำนวณ
- `scenarios` = ปุ่มสถานการณ์ขาย [ชื่อ, ยอดขายต่อวัน (บาท)]
- `LINE_URL` = ลิงก์ LINE

## หน้าเช็คทำเลว่าง: 2 โหมด

- **ตอนนี้ (`SHEET_CSV_URL` ว่าง)**: โหมด "ทีมงานตรวจให้" ลูกค้าเลือกพื้นที่ ปักหมุด แล้วกดคัดลอกข้อความพร้อมพิกัดส่งทาง LINE หน้าเว็บจะไม่ตอบเองว่า "ว่าง"
- **เมื่อมีชีตรายชื่อสาขาชาโทรี่**: ใส่ลิงก์ CSV ที่เผยแพร่แล้วใน `SHEET_CSV_URL` หน้าเว็บจะตอบ "ว่าง / มีสาขาแล้ว" ทันที พร้อมแผนที่ภาพรวมและรายชื่อสาขา
  รูปแบบคอลัมน์ดูที่ `check-branch/data/branches-sample.csv` วิธีจัดการชีตเหมือนคู่มือของชานัว (`../docs/คู่มือแอดมิน-เช็คสาขาว่าง.md`)
  ปรับระยะห่างขั้นต่ำ (`RADIUS_KM`) และจังหวัดเขตเมืองให้ตรงเงื่อนไขของชาโทรี่ก่อนเปิดใช้

## ข้อมูลแพ็กเกจ (ยืนยันแล้ว)

- **TORii mini 39,000 บาท** พื้นที่ 10 ตร.ม. ขึ้นไป หรือซุ้มขนาด 2×2 เมตร
- **TORii Kiosk 89,000 บาท ไม่รวมซุ้ม** สั่งซุ้มเพิ่ม 50,000 บาท ค่าขนส่งซุ้มคิดตามระยะทาง
  (ในตัวคำนวณมีช่องติ๊ก "รวมค่าซุ้มคีออส" ค่าเริ่มต้นคือรวม · แก้ราคาซุ้มที่ `addon` ใน `SITE`)
- **CHATORY Store 499,000 บาท** พื้นที่ 30–100 ตร.ม.

## ข้อมูลที่ยังรอ

- รายการของที่ได้ในแต่ละแพ็กเกจ
- ลิงก์เพจ Facebook (ใส่ได้ที่ส่วน "สนใจแฟรนไชส์")
- รูปต้นฉบับความละเอียดสูง (ดูหัวข้อถัดไป)

## รูปภาพ (`assets/`)

รูปทั้งหมดตัดมาจากภาพตัวอย่างขนาดเล็กของงานใน Canva (กว้างประมาณ 150–340 px) จึงอาจไม่คมบนจอความละเอียดสูง
